Gate 2: Multi-locale blog

Query-index listing, tags, placeholders, two locales and a block library for authors.

The brief

Level 2 · Intermediate · About 20 to 30 hours. Content as of 9 Nov 2026.

Acme Financial wants an English and French blog. Authors must be able to publish independently, and readers must be able to browse by topic.

Acme Financial is fictional. Use only sites and assets you have permission to use.

What to build

  • A blog listing page, driven by a query index
  • Tags on posts, with a view filtered by tag
  • Placeholders for repeated interface text
  • English and French locales in parallel folders
  • A block library or documented templates for authors
  • An hreflang-enabled sitemap, and correct metadata

Suggested milestones

Decide index columns, tag values and folder structure.

Set up the query index, and confirm its JSON.

Build a listing block that filters and paginates.

Add French pages, placeholders and nav.

Publish the block library, and have someone else create a post.

Add hreflang, check robots and the sitemap.
