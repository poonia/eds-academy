Practice

9 code labs where you write and check real block code, and 10 debug cases where you find the cause of a real-world fault. Everything runs in your browser, with nothing to install.

How it works

Code labs

Write a block’s decorate() function against delivered markup. Automatic checks tell you what works, with hints if you are stuck.

Debug cases

Start from a symptom, open only the evidence you need, and name the cause. Then see the fix.

Your progress

Results are saved in this browser, with the rest of your progress. Code you write is saved as a draft.

All exercises

Each one sits in the topic that teaches it. Open it there, so the explanation is beside you.

One project, four stages

The four capstones form one continuing project for Acme Financial, a fictional company: a microsite first, then a multi-locale blog, then a migrated section with go-live, and finally an enterprise architecture. The module labs and exercises build the skills each stage needs.

StageCapstoneWhat you build
Gate 1Personal micrositeAn aem.live site with nav, footer, 5 pages and a custom block scoring 100 on mobile Lighthouse.
Gate 2Multi-locale blogQuery-index listing, tags, placeholders, two locales and a block library for authors.
Gate 3Migrated sectionA real or sample site section moved to EDS with redirects, analytics in the delayed phase, CSP and a go-live checklist.
Gate 4Enterprise reference architectureMulti-brand platform design, governance model, block catalog, migration plan and operating runbook.

Code labs run your code in an isolated frame with simplified versions of the aem.js helpers, so they can differ slightly from a real project. Use them to practise the pattern, then try it with aem up in a real repository.
