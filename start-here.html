How EDS Academy works

Pick a track, set up a few free tools, and work through modules in order. Each module teaches every topic with a visual, an example and a quick check, then ends with a lab, a quiz and a cheat sheet.

Anatomy of a module page

Every module follows the same shape so you always know where you are.

Mark each topic Done as you go. The sidebar, the home page and the header ring all track it.

Verify callouts flag details that change often or that could not be confirmed. Check them on aem.live before relying on them.

Examples use a fictional bank and credit union. Swap in your own organization's sites when you do the labs.

Set up your tools

All free. You need the first three for Category A labs, Sidekick from module B2, and the rest from module C1 onwards.

  • A desktop browser with DevTools (Chrome or Edge recommended)
  • Access to PageSpeed Insights (pagespeed.web.dev)
  • A terminal with curl
  • A GitHub account
  • Node.js (current LTS) and npm
  • VS Code or another code editor
  • The AEM CLI (npm install -g @adobe/aem-cli), used in module C1
  • The AEM Sidekick browser extension, used in module B2
  • A Google Drive or SharePoint folder you can share with the AEM service, used in the developer tutorial

How long it takes

Study times come from what each module contains: reading at 150 words a minute, time on each diagram and example, questions, flashcards, simulators and the lab. Capstones and exams are extra. They are estimates, and you may take longer on a topic that is new to you or skip ahead on one you know.
